1.0 Why a finance student codes

The analysts I want to work with pull their own data and clean it before they form a view. I decided to learn that as a student: I taught myself on weekends, alongside a full finance courseload and for no course credit, and this toolkit is what I built.

3.0 Under the hood

I kept the core short and can explain each line of it:

signals.py · core loop
# pull → clean → compute → flag
prices = pull(ticker).clean()
sma50, sma200 = prices.rolling(50).mean(), prices.rolling(200).mean()

cross = (sma50.shift(1) <= sma200.shift(1)) & (sma50 > sma200)
if cross.any():
    flag("GOLDEN CROSS ▲", date=cross.idxmax())   # same rule as the chart above

4.0 Roadmap

The next release adds a backtesting module. It will measure how the flagged signals would have performed, so I can put a hit rate next to each one.
